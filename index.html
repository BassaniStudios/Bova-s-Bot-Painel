  2. Confirm UptimeRobot hits /health every 5 minutes.

GUIDE

Help & Guide

Auth

Use your Discord user ID + PANEL_ACCESS_KEY from Render. Staff role required on the main guild.

Bot silent?

Open Diagnostics → Health check. Keep UptimeRobot on /health every 5 min so Render Free does not sleep.

API base

Configured in js/config.js as BOVA_API.baseUrl → currently the Render service URL.

Removed

Polls web UI and /api/poll. Use Nitro Raffles in Discord instead.
