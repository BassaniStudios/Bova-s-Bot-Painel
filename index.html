TICKETS

Configure category, staff role and log channel with /ticket_config, then post the panel with /ticket_panel. Closing a ticket auto-generates a transcript saved under data/transcripts/ and logs to bot-room.

Commands: /ticket_panel /ticket_config /ticket_close /ticket_add /ticket_remove /ticket_rename /ticket_transcript

BOOST THANK-YOU

Default channel: BOOST_CHANNEL_ID (1384173136638906407). Configure with /boost_config.

WEBLOGS

Toggles via /weblogs_config.
Joins/leaves → Info channel
Channel create/delete + staff actions → bot-room
Message delete/edit → message log channel

STATS

Peak hours use São Paulo timezone. Weekly media reset runs on Mondays (SP). Commands: /stats /topmedia

NAME HISTORY ARCHIVE

The bot stores join snapshots and every display/username change in data/namehistory.json and posts live alerts to bot-room. Live archive in this static panel is limited — export from Discord or paste JSON below for local view.

Discord: /namehistory @user · /namehistory_export
