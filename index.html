LOG ROUTING

Name changes + member registry → bot-room
Message delete / edit (with media links) → message log
Boost thank-you → boost channel
Staff moderation actions → bot-room + message log

POSTING FROM THIS PANEL

Static GitHub Pages cannot post as the bot. Auto-Role, Embed, Meets and AutoFeeds generate commands / JSON for you to run in Discord. API on Render is available: set BOVA_API.baseUrl in js/config.js. Calls require your Discord user ID + staff role.

TICKETS · SUGGESTIONS · REPORTS

Public panel channel: 📚┃tickets-suggestions · Private log: 📚┃ticket-logging. Members use buttons + modal; content never stays on the public panel channel.

Configure category, staff role and log channel with /ticket_config, then post the panel with /ticket_panel. Closing a ticket auto-generates a transcript saved under data/transcripts/ and logs to bot-room.

Commands: /ticket_panel /ticket_config /ticket_close /ticket_add /ticket_remove /ticket_rename /ticket_transcript

TUTORIAL — COMANDOS DO BOT (PORTUGUÊS)

Lista completa dos slash commands disponíveis. Digite / no Discord e escolha o comando. A maioria das ações de staff exige permissão de gerenciar mensagens ou administrador.

UTILIDADES
/ping — Mostra a latência do bot.
/info — Informações do bot, servidor e usuário.
/help — Painel cyberpunk interativo de ajuda no Discord.
/timestamp — Gera timestamp do Discord a partir de data/hora.
/avatar — Mostra o avatar de um usuário.
/servericon — Mostra o ícone do servidor.
/membercount — Contagem de membros (humanos e bots).
/userinfo — Detalhes de um membro (ID, entrada, cargos…).
/serverinfo — Informações gerais do servidor.
/say — Staff — Faz o bot enviar uma mensagem em um canal.
PAINEL WEB
/panel — Staff — Envia o link do painel web + chave de acesso (só quem tem o cargo).
ENQUETES (POLLS)
/poll — Staff — Cria enquete com botões e resultado ao vivo.
/poll_end — Staff — Encerra uma enquete pelo ID.
/poll_list — Staff — Lista enquetes ativas.
MEETS & ANÚNCIOS
/meet — Staff — Publica anúncio de meet (data, local, hosts…) com lembretes.
AUTO-ROLE
/autorole_panel — Publica o painel de cargos no canal.
/autorole_add — Adiciona um cargo ao painel.
/autorole_remove — Remove um cargo do painel.
/autorole_list — Lista cargos configurados.
/autorole_config — Define título/descrição do embed.
AUTO-FEEDS (mensagens agendadas)
/autofeed_add — Agenda mensagem (intervalo ou horário fixo).
/autofeed_list — Lista feeds.
/autofeed_remove — Remove um feed pelo ID.
/autofeed_toggle — Liga/desliga um feed.
TICKETS
/ticket_panel — Publica o painel para abrir ticket.
/ticket_config — Configura categoria, cargo staff, canal de log.
/ticket_close — Fecha o ticket atual (com transcript).
/ticket_add — Adiciona membro ao ticket.
/ticket_remove — Remove membro do ticket.
/ticket_rename — Renomeia o canal do ticket.
/ticket_transcript — Gera transcript manual.
COMANDOS PERSONALIZADOS
/cmd_add — Staff — Cria um comando/tag de texto ou embed.
/cmd_remove — Remove um comando personalizado.
/cmd_list — Lista comandos personalizados.
/run — Executa um comando personalizado pelo nome.
STICKY (mensagem fixa no final do canal)
/sticky_set — Define a mensagem que fica no fim do canal.
/sticky_clear — Remove o sticky do canal.
ESTATÍSTICAS & MÍDIA
/stats — Estatísticas de atividade do servidor.
/topmedia — Ranking de mídia (scores / top da semana).
HISTÓRICO DE NOMES
/namehistory — Consulta histórico de nicks/usernames de um membro.
/namehistory_export — Exporta o arquivo de histórico (staff).
CONVITES & BOOST
/invitepanel — Painel para solicitar convite (com cooldown).
/boost_config — Configura mensagem de agradecimento de boost.
LOGS
/weblogs_config — Liga/desliga tipos de log (join, leave, edit, canais…).
MODERAÇÃO (limitada de propósito)
/delete — Apaga uma mensagem pelo ID (anônimo para o chat).
/purge — Apaga várias mensagens recentes (1–100).
Kick/ban não existem neste bot por decisão do projeto.
ANIVERSÁRIOS (painel fácil)
/birthday_panel — Publica o painel com botões (lista / registrar / editar / signo).
/birthday_announce_channel — Canal dos avisos diários de aniversário.
Membros usam só botões e menus — sem digitar data em slash.
BOAS-VINDAS & VOZ
/welcome_config — DM de entrada, log de voz, bot entrar em call (opcional).
/welcome_test — Testa a DM de boas-vindas em você.
BACKUP & BANCO (SQLite)
/backup_now — Admin — Força backup do banco no canal de backup.
/backup_export — Admin — Exporta DB/JSON para você (efêmero).
/db_status — Admin — Path, tamanho, última auto-backup.
/backup_hint — Explica como o auto-backup funciona no Render free.

Dica: no Discord, ative o Modo Desenvolvedor (Configurações → Avançado) para copiar IDs de canais, mensagens e usuários.
