FERRAMENTAS

Message Log

Registro de mensagens apagadas e editadas. Configuração só no Discord — este painel explica e mostra o estado esperado.

Padrão atual: monitora todas as salas de texto, exceto a lista de ignore. Canal de destino padrão: 1432715549116207248. Sala ignorada por padrão: 1540532050531061921.
LOCKED — comandos /msglog e /msglog_test só para Líder / dono. Cada comando tem o parâmetro opcional visibility: Ephemeral (só você vê) ou In channel (público).

/msglog status

Mostra canal de log, ignores, whitelist de watch e tamanho do cache.

/msglog channel

Define onde os embeds de delete/edit serão postados.

/msglog channel_reset

Volta o destino para o padrão do env / hardcoded.

/msglog ignore_add

Para de logar delete/edit na sala escolhida.

/msglog ignore_remove

Volta a logar a sala (se a whitelist não bloquear).

/msglog ignore_list

Lista salas ignoradas.

/msglog watch_add

Adiciona à whitelist. Com lista não vazia, só essas salas são monitoradas.

/msglog watch_remove / watch_clear

Remove da whitelist ou limpa tudo (volta a monitorar todas, exceto ignores).

/msglog_test

Envia um embed de teste no canal de log e mostra status do cache.

AJUDA

Guia rápido

Como usar este painel e o que ficou só no Discord.

1
Autenticação
Informe seu ID Discord e a chave (PANEL_ACCESS_KEY). O bot confere se você tem o cargo de staff/Líder.
2
API
Todas as ações web passam por BOVA_API.baseUrl (Render). Se a latência estiver alta, o free tier pode estar “acordando”.
3
Meets & embeds
Use as abas com prévia antes de publicar. O bot precisa de permissão de ver + enviar + embeds no canal.
4
Message log
Configure no Discord com /msglog. O painel só documenta; não altera ignore/watch pela web.
5
Removidos deste bot
Arcade (Love Professor, Nazar, Horoscope), Nitro Raffles e Economia → bot BovasGames.
Suporte: em caso de falha de sync, use Diagnósticos → Sincronizar, ou no Discord /sync_commands (Líder).
