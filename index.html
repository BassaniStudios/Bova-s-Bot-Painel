1. Authenticate

Use your Discord user ID and the private panel key. The key is not embedded in this website.

2. Configure

Use web controls for timestamp, meets, embeds, polls and DM inbox. Use Discord slash commands for deeper admin tools.

3. Verify

Dashboard, Server and Audit confirm the bot and database are healthy.
