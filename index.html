HOW TO USE
  1. /help — Open the cyberpunk panel inside Discord.
  2. Auto-role — Configure roles here or with /autorole_add, then /autorole_panel.
  3. Meets — Build the announcement here, post with /meet (optional 30-min reminder).
  4. Stats — Bot tracks activity automatically; staff uses /stats and /topmedia.
  5. This panel — Staff only via /panel + access key.
